## About
Original interactive-fiction game presented through a fictional chat and operations interface. Players investigate communities, complete missions and make decisions that affect progress.

## Gameplay systems
- Chat-inspired interface and fictional communities
- Guided onboarding and tutorial
- Branching dialogue and consequences
- Member profiles and investigation tools
- Missions, objectives and boss encounters
- Browser progress persistence
- Modals, notifications and live status feedback
- Mobile-first app-inspired UI

Younger playtesters completed the experience and provided informal feedback. Aggressive decisions intentionally make some routes harder.

## Technology
HTML5 · CSS3 · Vanilla JavaScript · Local storage · GitHub Pages

## Run locally
```bash
git clone https://github.com/abrilvillita/Tiburones.exe.git
cd Tiburones.exe
```
Open `index.html`; no server is required.

## What I practiced
State-driven interfaces, narrative logic without a game engine, consequence systems and user feedback.
